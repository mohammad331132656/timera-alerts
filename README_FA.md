# ربات اطلاع‌رسانی باز شدن روز جدید در تایمرا

این نسخه برای آدرس `https://timera.ir/b/10499` نوشته شده است.

**دقیقاً چه کاری می‌کند؟**

- در نخستین اجرای واقعی، برای **هر روزی از امروز به بعد که طبق داده‌های سایت حداقل یک نوبت قابل رزرو داشته باشد**، یک پیام مستقل به کانال تلگرام می‌فرستد؛ پیام‌ها از قدیمی به جدید مرتب می‌شوند.
- در اجراهای بعدی فقط روزهایی را اعلام می‌کند که قبلاً برای آن‌ها پیامی نفرستاده است. تغییر تعداد سانس‌های همان روز پیام تازه‌ای تولید نمی‌کند.
- اگر سه روز هم‌زمان باز شوند، سه پیام جدا، به ترتیب تاریخ می‌فرستد.
- تاریخ‌های گذشته اعلام نمی‌شوند. تاریخ هر روز برای همیشه در فایل `.timera_state.json` ذخیره می‌شود؛ حذف و بازگشت یک روز پیام تکراری نمی‌سازد.
- بررسی هر ۱۵ دقیقه انجام می‌شود (اجرای زمان‌بندی‌شده GitHub ممکن است چند دقیقه دیر شود).
- **فقط خبر می‌دهد؛ رزرو و پرداخت نمی‌کند.**

### تعریف «روز باز»

طبق JavaScript ذخیره‌شده سایت تایمرا، رویدادهای تقویم با شناسه `ID = -2` با ویژگی `reserveAble` مشخص می‌شوند. در این نسخه روزی باز تلقی می‌شود که حداقل یک رویداد قابل رزرو داشته باشد. روزی که فقط سانس‌های تکمیل ظرفیت دارد پیام نمی‌گیرد؛ این یک انتخاب محافظه‌کارانه برای جلوگیری از اعلام اشتباه است. در صورت نیاز به اطلاع‌رسانیِ «انتشار روز در تقویم حتی اگر همه سانس‌ها پر باشند»، باید نمونه واقعی پاسخ API بررسی شود.

### نصب در کانال تلگرام (بدون نیاز به سرور پولی)

1. از طریق [@BotFather](https://t.me/BotFather) با `/newbot` ربات بسازید. توکن را محرمانه نگه دارید.
2. کانال خودتان را بسازید و ربات را در **Administrators** اضافه کنید؛ دسترسی **Post Messages** را فعال کنید.
3. اگر کانال عمومی است، آیدی کانال را مثل `@my_booking_channel` به‌عنوان شناسه چت استفاده کنید. اگر خصوصی است، به شناسه عددی کانال نیاز دارید (معمولاً با `-100` شروع می‌شود).
4. در GitHub مخزن **Public** بسازید. **محتویات** این پوشه را مستقیماً در ریشه مخزن آپلود کنید؛ فایل `.github/workflows/check.yml` حتماً باید سر جای خودش باشد.
5. در `Settings > Secrets and variables > Actions` دو **Repository secret** بسازید:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات؛ **هرگز داخل فایل یا چت عمومی قرار ندهید**.
   - `TELEGRAM_CHAT_ID` = شناسه کانال (آیدی عمومی به صورت `@...` یا شناسه عددی کانال خصوصی).
6. به `Actions > Timera new-day alerts > Run workflow` بروید. **همان اجرای اول، تمام روزهای باز از امروز را جداگانه اعلام می‌کند**. برای تست اولیه کانال، بهتر است ابتدا ربات را ادمین یک کانال آزمایشی کنید.
7. فایل `.timera_state.json` به کمک خود workflow در مخزن ذخیره می‌شود. آن را حذف نکنید، چون در این صورت تاریخچه پیام‌ها از دست می‌رود و در اجرای بعدی ممکن است پیام‌های قدیمی دوباره فرستاده شوند.

> اگر GitHub اجازه ثبت تغییرات را نداد: در `Settings > Actions > General > Workflow permissions` دسترسی `Read and write permissions` را فعال کنید.

### تست بدون ارسال پیام به کانال

در رایانه‌ای که پایتون و اینترنت دارد:

```bash
pip install -r requirements.txt
python monitor.py --demo       # بدون اینترنت: شبیه‌سازی باز شدن چند روز
python -m unittest discover -s tests -v  # آزمون‌های خودکار
python monitor.py --dry-run    # API واقعی را می‌خواند، ولی پیام نمی‌فرستد
```

**آزمایش اتصال واقعی به Timera در محیط تهیه این پروژه ممکن نبود:** درخواست مرورگر ابزار بررسی فقط `Loading...` نشان می‌دهد و محیط اجرای پایتون به دامنه سایت دسترسی شبکه نداشت. بنابراین کد بر اساس JavaScript واقعی فایل ذخیره‌شده کاربر نوشته شده اما هنوز پاسخ زنده API تأیید نشده است. اولین اجرای واقعی ممکن است نیاز به بررسی پاسخ API داشته باشد. همچنین هنوز بدون توکن و ادمین‌شدن ربات، ارسال واقعی در کانال آزمایش نشده است.

### نکات

- از وضعیت عمومی رزرو استفاده می‌کند. دورزدن محدودیت‌ها یا ورود به حساب کاربری ندارد.
- فاصله ۱۵ دقیقه بین بررسی‌ها در نظر گرفته شده تا فشار غیرضروری ایجاد نشود.
- در وضعیت عادی پیام‌ها تکرار نمی‌شوند. مانند هر سیستم اعلان خارجی، در شرایط نادرِ ارسال موفق تلگرام همراه با خرابی ذخیره وضعیت یا خطای شبکه، تضمین ریاضی «دقیقاً یک بار» ممکن نیست؛ اگر فایل وضعیت ذخیره شود، تکرار اتفاق نمی‌افتد.
